剑网3 艺人助手 — 0.1.77 React/WebView2界面试用候选

请保留完整文件夹，不要只复制exe；engine包含识别脚本与模板。
正常使用：由你双击JX3Artist.exe，并按Windows提示完成原有管理员授权。
只看界面：双击Preview.cmd，使用隔离演示数据，不读取或操作游戏，不需要助手提权。
本机需要.NET 10 Windows Desktop Runtime及Microsoft Edge WebView2 Runtime；真实识别仍使用原有Python环境。
界面资源已打包在web目录，不依赖浏览器标签页、开发服务器或在线网页。

顶部：旗舰端/单开模式、皮肤、菜单。多开与无界端均为规划中，不能选择。
主页：选择1/2/3、自定义正整数或持续运行；运行中不改计划。
默认F7开始、F8停止；菜单→设置可点击键帽录入自定义快捷键。
支持F1–F24（F12除外）及Ctrl/Alt组合键，可加Shift；冲突会提示并保留原设置。
开始前须自行站到安全、平坦的位置，并在江湖百态打开艺人，保持开始界面可见。
勾选后续自动接管：续演时切回游戏并移动鼠标；关闭时会提醒，允许后才接管。
停止只停止后续辅助，不结束游戏中正在进行的表演。动效不延迟停止命令。

经验仅为观察时段估算：本次/累计，未知时段不补算。实际到账精度仍未知。
记录区可看实际状态与诊断；菜单可导出问题报告，保存前可预览，不自动上传。
邮件反馈依赖Windows默认邮件应用；未配置时可复制邮箱147984829@qq.com。
GitHub Issues尚未配置，待作者上传仓库并确认地址后补齐。

本候选做程序、真实WebView2/后端隔离联调与界面对照；没有本版本游戏实机验收。
62仍是既有本机正常使用基线。阶段2、原生1280输入和跨机/长期缺口未关闭。

窗口顶栏已与界面合并：拖动顶部空白/标题可移动窗口，右上可最小化、最大化/还原和关闭，支持Alt+F4。
旧版免提醒设置升级后会补一次准备提醒，确认后可重新选择不再提示。

遮挡检查：请露出完整的紫色开始表演图标；左侧金色装饰可被遮挡；未确认时助手不会据此点击。
设置→偏好设置可清零累计经验，须先停止辅助并再次确认；本次和历史记录保留。
经验文件升级为v3，原v2有逐字节备份。旧版无法读取v3时会保留原文件并报保存故障，不会按旧格式覆盖。
